实验室配方计算器 · PWA 师门分享版
=================================

这个文件夹已经可以作为静态网站直接部署。

文件说明
--------
index.html               主程序
manifest.webmanifest     PWA 安装信息
sw.js                    离线缓存
icons/                   iPhone / Android / PWA 图标

使用方式
--------
1. 将【整个文件夹内的所有文件】保持原目录结构上传到静态网页托管服务。
2. 确保 index.html 位于网站根目录。
3. 获得 HTTPS 网页链接后，把链接发到师门群即可。
4. iPhone：建议用 Safari 打开 → 分享 → 添加到主屏幕。
5. Android / Chrome：可使用网页中的“添加到主屏幕/安装到手机”。

数据说明（重要）
----------------
- 药品库和历史记录默认保存在“当前浏览器/当前设备”的 localStorage 中。
- 同一个网址，不同成员默认拥有各自独立的数据，不会互相改乱。
- 要把你整理好的药品库给师门成员：
  你：点击“导出备份” → 把 JSON 文件发给对方
  对方：点击“导入备份” → 选择 JSON 文件
- 换手机、清除浏览器网站数据前，也建议先导出备份。

本地预览
--------
直接双击 index.html 时，配方计算和药品库功能可以使用，
但浏览器出于安全限制，不会启用 Service Worker / PWA 离线安装。
完整 PWA 功能需要通过 HTTPS 网站链接访问。

后续如果需要“管理员改一次药品库、全师门自动同步”，
需要再增加云端数据库与权限功能；当前版本 intentionally 使用本地数据，
优点是不需要注册账号、部署简单、成员之间互不干扰。
